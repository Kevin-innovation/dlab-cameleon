# 맵 전면 재개편 계획서

상태: M0~M6 완료 (2026-09-19) · 남은 것 M7 플레이테스트(사용자)
선행 문서: [gameplay-contract.md](gameplay-contract.md) §4 맵 계약, [online-rooms-plan.md](online-rooms-plan.md)

## 0. 왜 지금 "모델하우스"처럼 보이는가

| 증상 | 원인 (코드) |
|---|---|
| 천장이 뚫려 보임 | (M0 캡처로 확인) 천장 평면은 있지만 **아래에서 빛을 전혀 받지 못해 검게 렌더링**된다(반구광 바닥색·태양광이 위에서만 옴). 게다가 **실내 벽이 2.45m에서 끝나**(`stageLayout` `h = min(ceiling-0.24, 2.45)`) 벽 위 1~3m가 검은 허공이 된다 |
| 야외 맵도 실내 같음 | 농장(천장 6m)·하수도에도 같은 평면 천장. 하늘·태양·지평선이 없다 |
| 벽이 종이 같음 | 내부 벽 두께 0.16~0.36, 몰딩·문틀·창문 없음. 색만 다른 박스 |
| 방이 아니라 전시장 | 방 분할이 "중앙 가로벽 1개 + 문 1개"뿐. 복도·모서리·막다른 곳·창이 없어 시야가 한 번에 트임 |
| 소품이 떠 있음 | 가구가 벽에 붙지 않고 바닥 중앙에 산발 배치. 러그·커튼·전선·쓰레기 같은 "생활 흔적" 없음 |
| 조명이 평평함 | 반구광 + 태양 1개 + 포인트 2개. 실내인데 창에서 들어오는 빛, 천장 조명 기구, 어두운 구석이 없다 |

결론: 소품을 더 넣는 수준이 아니라 **공간을 만드는 방식**(벽·천장·조명·구역)을 바꿔야 한다.

---

## 1. 목표

1. 맵을 보는 순간 실내/야외가 구분된다. 실내는 벽이 천장까지 닿고 천장에 조명 기구가 있다. 야외는 하늘·지평선·태양이 있고 경계는 울타리·건물·절벽 같은 "이유 있는" 벽이다.
2. 각 맵은 3개 이상의 **성격이 다른 구역**(밝은 곳/어두운 곳, 넓은 곳/좁은 곳, 높은 곳/낮은 곳)과 복도·모서리로 이어진다. 한 지점에서 맵 전체가 보이지 않는다.
3. 숨을 곳이 "가구 뒤"만이 아니라 **커튼 뒤·테이블 아래·선반 사이·어두운 구석·풀숲·건초 더미·파이프 틈**처럼 맵의 성격에서 나온다.
4. 데스크톱 60fps / 모바일 30fps 예산을 지킨다.

## 3. 새 맵 계약

### 3.1 맵 타입

```ts
type MapKind = "indoor" | "outdoor" | "mixed";
type GameMap = {
  kind: MapKind;
  ceiling: number;           // indoor: 실제 천장 높이(2.8~3.4), outdoor: 하늘 돔 높이(사용 안 함)
  sky?: { top: string; horizon: string; sun: { azimuth: number; elevation: number; color: string } };
  ceilingStyle?: "plaster" | "tiles" | "concrete" | "beams";
  lighting: "day" | "fluorescent" | "dim" | "dusk";
  zones: Zone[];             // 구역 정의 (이름, 바닥 범위, 밝기, 성격)
  rooms: RoomDef[];          // 벽·문·창을 방 단위로 생성 (§3.2)
  props: BoxDef[];           // 가구·소품 (벽 스냅 옵션)
  decals: DecalDef[];        // 러그·얼룩·그래피티·전선
  spawns / hunterSpawns
};
```

### 3.2 방 단위 구조 (RoomDef)

지금은 벽을 박스 하나씩 손으로 놓는다. 대신 **방을 선언하면 벽·문·창·몰딩·천장이 생성**되게 한다.

```ts
type RoomDef = {
  id: string;
  rect: { x: number; z: number; w: number; d: number };
  wall: { thickness: number; height: number; material: MaterialId };  // height = ceiling
  openings: Array<
    | { kind: "door"; side: "n" | "s" | "e" | "w"; at: number; width: number; door?: boolean }
    | { kind: "arch"; side; at; width }
    | { kind: "window"; side; at; width; sill: number; height: number }
    | { kind: "gap"; side; at; width }   // 벽 없는 구간(야외 울타리 틈 등)
  >;
  ceiling?: { style: CeilingStyle; fixtures: Array<{ x: number; z: number; kind: "fluorescent" | "pendant" | "spot" }> };
};
```

생성기(`src/lib/maps/build.ts`)가 방 목록에서:
- 벽 세그먼트(개구부 제외)를 천장 높이로 생성, 인접한 방끼리 벽을 공유(중복 제거)
- 문틀·창틀·굽도리(몰딩) 메시 추가
- 실내: 방마다 천장 판 + 조명 기구 메시 + 실제 광원(모바일은 이미시브만)
- 야외: 천장 없음, 하늘 돔(그라디언트 셰이더) + 태양 방향광 + 지면 밖 지평선(먼 나무·건물 실루엣 플레인)

### 3.3 구역(Zone) 계약

각 맵 3~5개 구역, 각 구역은 다음 중 서로 다른 조합을 가진다.

| 축 | 값 |
|---|---|
| 밝기 | 밝음(창·조명 밑) / 어두움(조명 꺼짐, 구석) |
| 크기 | 넓은 홀 / 좁은 복도 / 작은 방 |
| 커버 | 큰 가구 / 낮은 가구 / 수직 구조(선반·파이프·기둥) |
| 위험 | 술래 스폰과의 거리, 출입구 수 |

감사(`gameplay-audit`)에 추가: 구역 수, 구역 간 밝기 차, 임의 지점에서 보이는 맵 비율(시야 커버리지 ≤ 45%), 막다른 곳 ≥ 2, 순환 루트 ≥ 2.

### 3.4 맵별 컨셉

| 맵 | 종류 | 구역 | 시그니처 숨을 곳 | 조명 |
|---|---|---|---|---|
| **백룸** (어려움) | indoor, 천장 2.9, 타일 천장 + 형광등 | 사무실 칸막이 숲 / 복사실·탕비실(좁음) / 회의실(창 있음, 밝음) / 창고(형광등 꺼짐, 어두움) / 긴 복도 | 칸막이 사이 의자 밑, 캐비닛 옆, 꺼진 형광등 구역 벽, 카펫 얼룩 | 형광등 깜빡임 1개, 창고 어둠 |
| **저택** (쉬움) | indoor, 천장 3.4, 석고 천장 + 샹들리에 | 무도회장(넓음·밝음) / 서재(책장 벽) / 주방(타일·수납) / 복도·계단참(부분 2층 다락, Q3) / 온실(창 많음) | 커튼 뒤, 테이블보 아래, 책장 사이, 계단 밑 | 창에서 오는 낮 빛, 샹들리에, 복도는 어둡게 |
| **농장** (쉬움) | outdoor + 헛간 실내(mixed) | 마당(건초·트랙터·울타리) / 헛간 실내(어둡고 높음) / 닭장·돼지우리(낮은 울타리) / 창고 | 건초 더미 옆, 헛간 대들보 그늘, 울타리 기둥 옆, 트랙터 밑 | 낮 태양 + 그림자, 헛간 안은 틈새 빛 |
| **하수도** (보통) | indoor 터널, 천장 2.6~3.2, 콘크리트 + 맨홀 빛 | 메인 터널(길고 어두움) / 펌프실(기계·파이프) / 정비 창고 / 수로 옆 좁은 길(물) | 파이프 뒤, 펌프 기계 사이, 맨홀 빛 바깥 어둠, 수로 벽 이끼 | 맨홀에서 떨어지는 빛 기둥, 비상등 |
