## 2. 원작 참고 (MECCHA CHAMELEON)

Steam 페이지에는 스테이지별 설명이 없다. 확인된 방향성만 기록한다.

- 손그림 느낌의 **채도 높은 색면**. 위장은 "배경의 큰 색면에 몸을 맞추는" 게임이므로 벽·바닥·가구가 **크고 단순한 색 덩어리**여야 한다. 사실적인 노이즈 텍스처보다 **면 단위 색 구분**이 중요.
- 스테이지는 실내가 많고(방·복도), 가구·소품이 벽에 붙어 있어 "가구 옆 벽 색에 맞추기"가 기본 전략.
- 밝기 차이(그늘/조명 아래)가 발견 난이도에 영향.

→ 웹판 방향: 사실적 재질보다 **또렷한 색면 + 확실한 명암 구역**. 천장·벽·바닥이 서로 다른 색이어야 공간이 읽힌다.

## 3. 맵별 시각 레퍼런스 메모

### 백룸 (indoor · 어려움)
- 인터넷 밈 "Backrooms Level 0": 노란 벽지(#e8d97a 계열), 축축한 카펫(#c9b95a), **타일 천장 + 형광등 그리드**(차가운 백색 #f4f6e8), 일부 구역 형광등 꺼짐(#3a3520).
- 공간 문법: 규칙 없이 이어지는 방과 복도, 막다른 곳, 기둥. 사무실 버전은 칸막이·캐비닛·복사기.
- 색 대비: 벽(노랑) / 카펫(황갈) / 천장(회백) / 칸막이(회색) / 캐비닛(진회색). 스포이드 후보 5색.

### 저택 (indoor · 쉬움)
- 무도회장: 크림 벽 + 금색 몰딩, 샹들리에, 큰 창(낮 빛), 붉은 카펫.
- 서재: 짙은 나무 벽·책장, 녹색 가죽, 어두운 조명.
- 주방: 흰 타일, 스테인리스, 밝은 창.
- 복도·다락: 좁고 어둡게. 계단 밑 공간.
- 색 대비: 크림 / 짙은 갈색 / 흰 타일 / 붉은 카펫 / 녹색.

### 농장 (outdoor + 헛간 · 쉬움)
- 마당: 밝은 하늘(#8fc7f0 → 지평선 #e7ecd9), 초록 풀, 갈색 흙길, 흰 울타리, 붉은 헛간 외벽, 건초(#d9a441).
- 헛간 실내: 어둡고 높은 천장(서까래), 틈새로 들어오는 빛줄기, 건초 더미.
- 그림자가 위장의 핵심(그늘 vs 햇빛).

### 하수도 (indoor 터널 · 보통)
- 콘크리트(#6b6f68) + 이끼(#4c6b4a) + 녹슨 파이프(#8a4a2a), 물(#2f5d5a).
- 낮은 아치 천장, 맨홀에서 떨어지는 빛 기둥, 비상등(주황).
- 긴 직선 터널 + 옆으로 빠지는 펌프실·창고.

## 4. 공통 규칙 (M1 설계 입력)

1. 천장은 **자체 발광(약한 emissive) 또는 앰비언트만으로도 보이는 재질**로. 검은 허공 금지.
2. 실내 벽 높이 = 천장 높이. 벽 위 틈 없음.
3. 맵당 스포이드 후보 색 5~7개, 각 색은 면적 5% 이상.
4. 구역별 밝기 프리셋 2단계 이상(밝음/어두움).
5. 야외는 하늘 돔 + 방향광 그림자 + 경계는 "이유 있는" 구조물.
