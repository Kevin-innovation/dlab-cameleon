# MECCHA CHAMELEON 웹판 기준 문서

상태: Phase 0 기준 고정 문서

이 문서는 웹판 `카멜론`의 게임성을 실제 `MECCHA CHAMELEON`에 맞추기 위한 기준 문서다. 원작 고증과 웹 서비스 확장을 같은 규칙으로 취급하지 않는다.

## 1. 자료 우선순위

1. [Steam 공식 스토어](https://store.steampowered.com/app/4704690/MECCHA_CHAMELEON/?l=english)
2. [Steam 공식 업데이트 목록](https://steamcommunity.com/app/4704690/announcements/)
3. 실제 게임 플레이 확인
4. 커뮤니티 가이드와 게시물

공식 자료로 확인되지 않은 항목은 원작 기능이라고 단정하지 않는다. 커뮤니티 자료는 구현 후보를 찾는 참고 자료로만 사용한다.

## 2. 공식 자료에서 확인된 핵심

- 플레이어는 **Seeker 팀**과 **Hider 팀**으로 나뉜다.
- Hider는 순백의 몸에 직접 색을 칠해 스테이지와 어울리게 만든다.
- 숨는 위치, 자세, 색·패턴을 맞추는 능력이 핵심 생존 수단이다.
- Seeker는 제한 시간 안에 모든 Hider를 찾으면 승리한다.
- 공개 매치와 인게임 채팅을 지원한다.
- 공식 업데이트에는 플레이어 수 표시, 조인 코드, Hunter TPS 시점, 탄약 제한 옵션, 도발 쿨다운, 페인트 네트워크 최적화, 카메라·벽 붙기·부유·끼임 수정이 포함되어 있다.

## 3. 아직 원작 기준으로 확정하지 않은 항목

다음 항목은 현재 웹판에 있더라도 원작 기본 규칙으로 취급하지 않는다.

- 감염 모드의 정확한 승패·전환 규칙
- Hunter 탄약의 기본값과 명중·빗나감 시 처리
- AI Hider와 AI Seeker의 행동 규칙
- 정확한 키보드 단축키와 기본 키 배치
- 모바일 화면과 터치 조작
- 웹판에서 사용할 라운드 시간
- 원작의 모든 자세·이모트 목록

이 항목들은 공식 자료 또는 실제 플레이 확인 뒤에만 기본 규칙에 포함한다.

## 4. 웹판에서 유지할 운영 정책

아래는 원작 사양이 아니라 이 서비스의 운영 결정이다.

- 한국 서버 통합 방 1개
- 한 방 최대 8명
- 실시간 접속자 목록
- 대기실 및 인게임 채팅
- 혼자 플레이할 수 있는 AI 연습전
- 모바일 가로 화면 지원
- Playroom 기반 실시간 동기화

원작 스토어의 권장 인원은 2~10명이며 호스트 네트워크에 따라 달라진다. 따라서 최대 8명은 원작 고증이 아니라 웹 운영 정책으로 표시한다.

## 5. 기본 모드 규칙 계약

Phase 1부터 기본 입장 경로는 다음 규칙을 사용한다.

```text
lobby
  -> prepare
  -> hide
  -> hunt
  -> reveal
  -> result
  -> lobby
```

### Hider

- 준비 시간에 직접 이동한다.
- 배경에서 색을 샘플링한다.
- 몸을 칠하고, 재질·패턴·자세를 조정한다.
- 물체와의 거리, 실루엣, 밝기 차이를 스스로 줄인다.
- 수색이 시작되면 움직임을 최소화하고 위치를 지킨다.

### Seeker

- 준비 시간에는 수색 영역에 들어오지 않는다.
- 수색 시작 후 직접 이동하고 카메라로 주변을 조사한다.
- 거리, 시야, 장애물, 색 차이, 실루엣을 바탕으로 발견을 판단한다.
- 전원을 찾으면 Seeker 승리, 제한 시간 종료까지 생존자가 있으면 Hider 승리다.

### 옵션 모드

- `infection`: 기본 모드가 아닌 커스텀 옵션으로 유지한다.
- `ammo`: 공식 규칙을 확인한 뒤 호스트 옵션으로 제공한다. 기본값은 Phase 1에서 비활성화한다.
- `hunterMode: ai`: AI 연습전에서만 우선 제공한다.

## 6. 현재 레포와의 차이

현재 구현은 다음 커스텀 요소를 기본 흐름에 섞고 있다.

- `src/lib/round.ts`에서 방 기본 모드가 `infection`이다.
- `src/lib/types.ts`와 `src/lib/round.ts`에 감염·고정 술래·AI 술래·탄약 규칙이 기본 상태로 노출되어 있다.
- `src/components/GameView.tsx`는 `R` 자세 순환과 `1~7` 자세 단축키를 사용한다. 이 키 배치는 원작과 동일하다고 확인되지 않았다.
- `src/lib/ai.ts`는 라운드와 봇 ID를 기반으로 숨을 장소 후보를 미리 만들고 최종 위치에 정착한다. 이는 탐색형 AI가 아니다.
- 채팅 패널은 현재 대기실 중심으로 노출된다.
- 통합 방 최대 8명과 모바일 가로 전용은 웹판 정책이다.
